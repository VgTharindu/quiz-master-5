# Student illustrations (optional image files)

Drop an image here with one of the names below and the student screens use it
automatically instead of the drawn SVG. No code changes are needed.

| File name | Used for | Recommended size |
|---|---|---|
| `kid-avatar.webp` | Avatar in the blue header | 256 × 256 |
| `kids-desk.webp` | Two kids studying, bottom of the login page | 1000 × 560 |
| `owl.webp` | Owl reading a book, shown when there are no tests | 300 × 300 |
| `star-mascot.webp` | Smiling star on the yellow banner | 300 × 300 |
| `trophy.webp` | Trophy (test cards, login, result) | 256 × 256 |
| `medal.webp` | Medal (test cards, rank) | 256 × 256 |
| `checklist.webp` | Checklist (test cards) | 256 × 256 |
| `book.webp` | Book (test cards) | 256 × 256 |
| `cat.webp`, `puppy.webp`, `bunny.webp` | Pets on the meadow and above questions | 300 × 300 |

- Use a **transparent background** (PNG or WebP with alpha).
- `.webp`, `.png`, `.jpg` and `.svg` all work. Keep each file under ~60 KB so the app stays fast on slow networks.
- Do not put text inside the images; Sinhala text is rendered by the app.
